# INTEGRALA — Landing inicial

Sitio estático de una sola página, sin dependencias ni proceso de build.

## Vista local
Abrí `index.html` en un navegador.

## Antes de publicar
1. Revisá el texto institucional para que describa con precisión al equipo y sus capacidades actuales.
2. Verificá que el servicio de chat en `https://professional-chat-pwa.vercel.app/` esté disponible.
3. Revisá disponibilidad legal de marca y dominio antes de publicar.

## Publicación
Puede alojarse como sitio estático en GitHub Pages, Cloudflare Pages, Netlify o Vercel. No requiere base de datos.

## Contacto
Los botones y la sección de contacto dirigen al chat de INTEGRALA, donde las personas pueden conversar con un bot o con alguien del equipo.
